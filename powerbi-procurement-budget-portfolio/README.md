## 🇬🇧 English

### 30-second overview

**Problem:** purchasing activity and budget consumption are hard to control when monthly and recurring orders are viewed separately.

**Solution:** one dashboard showing consumed budget, remaining budget and the orders behind it.

```mermaid
flowchart LR
    A[Budget] --> D[Dashboard]
    B[Orders] --> D
    C[Periods] --> D
    D --> E[Consumed / remaining / recent orders]
```

## 🇫🇷 Français

### Vue en 30 secondes

**Problème :** l’activité achats et la consommation budgétaire sont difficiles à piloter lorsque les commandes mensuelles et récurrentes sont vues séparément.

**Solution :** un dashboard unique montrant le budget consommé, le budget restant et les commandes qui l’expliquent.

```mermaid
flowchart LR
    A[Budget] --> D[Dashboard]
    B[Commandes] --> D
    C[Périodes] --> D
    D --> E[Consommé / restant / commandes récentes]
```
