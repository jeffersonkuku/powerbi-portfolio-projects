## 🧠 Ma logique d’analyse / My analytical logic

🇫🇷 Un bon dashboard ne montre pas seulement des chiffres : il permet de passer **du signal → à l’explication → au détail qui permet d’agir**.  
*🇬🇧 A good dashboard does not only show numbers: it lets the user move **from signal → to explanation → to the detail needed for action**.*

```mermaid
flowchart LR
    A[KPI global<br/>Headline KPI] --> B[Où ?<br/>Where?]
    B --> C[Pourquoi ?<br/>Why?]
    C --> D[Quel fournisseur / site / commande ?<br/>Which supplier / site / order?]
    D --> E[Action]
```
