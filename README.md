## Start here

This repository contains **five end-to-end Power BI portfolio projects** built to demonstrate more than dashboard design.

The projects show the complete analytical workflow used in professional reporting:

**Data preparation → Semantic modelling → DAX / KPI design → Business analysis → Dashboard UX → Decision support**

The strongest examples are:

1. **[Procurement & Financial Control Tower](./powerbi-procurement-financial-control-tower/)** — executive finance + procurement + supplier-performance cockpit.
2. **[SLA & Penalties Operations Portfolio](./powerbi-sla-penalties-portfolio/)** — advanced SLA, P95, backlog and contractual-risk analysis.
3. **[P2 Consumables Financial Monitoring](./powerbi-p2-consumables-financial-monitoring/)** — multi-year procurement, subcontracting, budget and invoicing model.
