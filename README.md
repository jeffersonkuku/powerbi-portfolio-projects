# Power BI Portfolio Projects

This repository contains two anonymized Power BI portfolio projects:

- **Financial Pilotage Portfolio** — financial steering, budget execution, supplier commitments and purchase-order analysis.
- **Procurement & Budget Portfolio** — procurement monitoring, consumables, budget consumption and purchase-order analysis.

## Projects

### 1. Financial Pilotage Portfolio
Location: `powerbi-financial-pilotage-portfolio/`

Includes:
- Power BI report (`.pbix`)
- Anonymized Excel dataset
- Project documentation
- SHA-256 checksums

### 2. Procurement & Budget Portfolio
Location: `powerbi-procurement-budget-portfolio/`

Includes:
- Power BI report (`.pbix`)
- Anonymized Excel dataset
- Project documentation
- SHA-256 checksums

## Privacy

These portfolio versions use anonymized/fictitious business data and are intended for public demonstration.
