## About this portfolio

This repository showcases two end-to-end **Power BI portfolio projects** built to transform operational and financial data into clear, actionable dashboards.

The projects demonstrate my ability to work across the full BI workflow:

**Data preparation → Modeling → KPI design → Business analysis → Data visualization → Decision support**

All datasets and business identifiers used here are **anonymized or fictitious** for public demonstration.

## 01 — Financial Pilotage Portfolio

**Objective:** provide a clear financial view of commitments, purchasing activity and budget execution.

### Key analysis areas

- Budget consumption and remaining budget
- Purchase-order monitoring
- Supplier commitments
- Ordered vs. received vs. invoiced amounts
- Financial reconciliation and control indicators
- Detailed transactional analysis

### Included files

- **Power BI report:** `dashboard/Portfolio_Pilotage_Financier.pbix`
- **Anonymized dataset:** `data/Portfolio_Commandes_Anonymise.xlsx`
- Project documentation
- SHA-256 integrity checks
