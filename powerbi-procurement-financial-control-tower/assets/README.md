## Publication rule

Only final validated screenshots should be published here. Screenshots containing Power BI edit panes, warning banners, broken visuals, `Corriger ceci` messages or pre-fix KPI formatting are intentionally excluded from the public portfolio.

An optional `preview.png` can be added later as the repository cover image.
