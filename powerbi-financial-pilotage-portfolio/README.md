## 🇬🇧 English

### 30-second overview

**Problem:** financial totals are difficult to explain without linking them to suppliers and individual purchase orders.

**Solution:** move from the overall financial position down to the transaction that explains it.

```mermaid
flowchart LR
    A[Budget / orders / invoices] --> B[Financial cockpit]
    B --> C[Supplier analysis]
    C --> D[Order detail]
```

## 🇫🇷 Français

### Vue en 30 secondes

**Problème :** les totaux financiers sont difficiles à expliquer sans les relier aux fournisseurs et aux commandes.

**Solution :** partir de la position financière globale puis descendre jusqu’à la transaction qui explique l’écart.

```mermaid
flowchart LR
    A[Budget / commandes / factures] --> B[Cockpit financier]
    B --> C[Analyse fournisseurs]
    C --> D[Détail commande]
```
