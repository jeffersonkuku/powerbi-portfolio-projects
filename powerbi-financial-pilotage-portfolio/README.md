# Power BI Financial Pilotage Portfolio

> **Financial steering dashboard inspired by reporting and analytical work carried out during my professional experience at ENGIE.**

## Professional context

This project is an **anonymized portfolio reconstruction inspired by financial steering and purchasing reporting solutions I developed during my experience at ENGIE**.

It demonstrates how I structured business data, designed financial KPIs and created Power BI dashboards to support budget and purchasing decisions in a professional environment.

> This repository is **not an official ENGIE deliverable**. All business names, datasets, suppliers, identifiers and sensitive operational details have been anonymized, modified or recreated for public presentation.
